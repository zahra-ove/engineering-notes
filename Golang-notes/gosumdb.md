## تفاوت go.sum و GOSUMDB در Go

در Go هنگام کار با dependencyها دو مفهوم مهم وجود دارد:

### 1) go.sum

فایلی داخل خود پروژه است.

* توسط خود Go ساخته و آپدیت می‌شود.
* شامل checksum (هش) ماژول‌ها و نسخه‌های آن‌هاست.
* باید همراه پروژه در Git commit شود.
* وظیفه‌اش این است که مطمئن شود dependency دانلودشده دقیقاً همان چیزی است که قبلاً تأیید شده.

مثال:

```
go.mod
go.sum
main.go
```

---

### 2) GOSUMDB

یک دیتابیس خارجی است، نه بخشی از پروژه.

* به صورت پیش‌فرض به این آدرس وصل می‌شود:

```
sum.golang.org
```

* هنگام دانلود dependency، Go checksum را با این سرویس بررسی می‌کند.
* هدفش جلوگیری از تغییر یا دستکاری dependencyهاست.

---

### جریان کلی:

```
go mod download
        |
        ▼
دریافت ماژول از GOPROXY
        |
        ▼
بررسی checksum با GOSUMDB
        |
        ▼
ثبت checksum در go.sum
```

---

### نکته مهم:

* `go.sum` داخل پروژه است و باید در Git باشد.
* `GOSUMDB` بیرون از پروژه است و فقط یک سرویس بررسی اعتبار است.
* خاموش کردن `GOSUMDB` (`GOSUMDB=off`) فقط بررسی آنلاین checksum را غیرفعال می‌کند و معمولاً راه‌حل اصلی مشکلات دانلود dependency نیست.

---

خلاصه یک خطی:

**go.mod می‌گوید چه dependencyهایی لازم داریم، go.sum اثر انگشت (checksum) آن‌ها را نگه می‌دارد، و GOSUMDB مرجع بیرونی برای تأیید این اثر انگشت‌هاست.**
